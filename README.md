## 关于打码

为保护尚未发表的成果，预览版已隐藏**实证结果与结论**部分：

- 摘要中的结论段（"结果表明 / 研究发现"之后）
- 全部图、表（含回归表、稳健性检验、异质性检验、机制检验）
- 结论与政策建议章节

保留可见的部分：标题、作者与署名信息、研究背景与文献综述、研究假设、变量定义与模型设定。

预览版 PDF 已做**栅格化处理**，隐藏内容无法复制、检索或还原。
